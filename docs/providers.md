# 翻译引擎配置

插件本身不收费，翻译服务可能收费。脚本不运营公共中转服务器，也不会从本地引擎自动切换到云引擎。所有引擎都使用你明确选择的配置。

## 浏览器本地翻译：实验功能

默认选择浏览器本地引擎，不需要 API Key。

1. 在支持相关能力的桌面浏览器中打开普通 HTTPS 网页。
2. 在设置中选择浏览器本地引擎和目标语言。
3. 源语言可自动判断；如果识别失败，或页面包含多种语言，手动指定源语言。
4. 主动点击翻译按钮。如果浏览器要求下载语言包，等待完成。

这个引擎需要页面所在的用户脚本上下文能够访问 `Translator`。浏览器支持相关 API 不代表所有 Tampermonkey 页面都能调用。脚本会运行时检测；缺少 API、语言对不可用或页面权限限制时会提示错误，不改用云 API。

首次语言包下载可能需要网络；下载后的翻译在浏览器内完成。浏览器版本、站点策略、用户激活和语言识别能力均会影响可用性。参见 [Chrome Translator API](https://developer.chrome.com/docs/ai/translator-api)与 [Edge Translator API](https://learn.microsoft.com/en-us/microsoft-edge/web-platform/translator-api)。

## Ollama 本机本地模型：零第三方 API 费用路径

本地模型运行在你自己的设备上。需要足够的内存、磁盘和计算能力，速度及翻译质量取决于模型。

1. 从 [Ollama 官网](https://ollama.com/)安装程序并运行本机服务。
2. 选择适合设备、支持所需语言和结构化 JSON 输出的本地模型，按其官方说明下载。
3. 在脚本中选择 Ollama，地址使用 `http://127.0.0.1:11434` 或 `http://localhost:11434`，模型填写已下载模型的准确名称。首版预填 `qwen3:4b`，并不代表脚本会自动下载它。
4. 执行连接检查，确认服务在线且模型存在，然后翻译一小段文本。

使用首版预填模型时，可先在本机终端执行：

```sh
ollama pull qwen3:4b
```

模型下载和本机资源需求由 Ollama 与模型决定；硬件不足时可选择更适合设备的本地模型，并在设置中填写对应名称。

脚本只接受 Ollama 回环地址，并拒绝被识别为云模型的配置。不要填写 `ollama.com` 云地址，不要把本机监听改为公网。使用本地地址调用云模型仍然不是本项目的免费本地路径。

Ollama 本地 API 不需要密钥；云模型和云 API 有独立认证及服务条件，见[官方认证说明](https://docs.ollama.com/api/authentication)。如遇连接失败，先确认服务启动、模型下载完成及油猴域名授权，不要直接设置允许所有来源。

## 有道智云：官方 API 与免费体验

有道提供免费体验，但官方 API 不保证永久免费。按当前[自然语言翻译定价](https://ai.youdao.com/DOCSIRMA/html/trans/price/wbfy/index.html)，新用户注册获得 **50 元体验资金**，先消费体验资金，耗尽后按接口用量扣账户余额。具体资格、余额及计费以控制台和官方条款为准。

1. 登录[有道智云](https://ai.youdao.com/)，创建可调用自然语言翻译服务的应用并完成服务绑定。
2. 获取应用 ID（接口字段为 `appKey`）及应用密钥。这里不是有道词典登录密码。
3. 在页面设置选择有道与语言对，点击“保存设置”。
4. 在 Tampermonkey 菜单中选择“设置当前引擎密钥”，输入应用 ID 和应用密钥；确认控制台余额、服务权限及配额后开始翻译。

接口地址为 `https://openapi.youdao.com/api`。脚本使用 v3 SHA-256 签名，按官方 API 进行调用；密钥不放入 URL。脚本内部把简繁中文等语言代码映射为有道代码。接入细节见[官方接口说明](https://ai.youdao.com/DOCSIRMA/html/trans/api/wbfy/index.html)。

有道的配置检查只检查本地凭据是否齐全，**不发送收费翻译请求**，也不能证明账户权限或余额有效。第一次实际翻译才会调用服务，可能消耗体验资金或余额。本项目不接入有道网页的私有接口、不提供共享密钥。

## DeepSeek：用户自带密钥

1. 在 [DeepSeek 开放平台](https://platform.deepseek.com/)创建 API Key，核对余额与计费规则。
2. 在页面设置选择 DeepSeek，核对服务地址和模型名称并保存。首版预填 `deepseek-flash`，模型可按官方可用列表更改。
3. 通过 Tampermonkey 菜单“设置当前引擎密钥”保存 DeepSeek 密钥。
4. 先翻译少量文本，确认结果与账户用量后再翻译整页。

官方基础地址为 `https://api.deepseek.com`。适配器使用 Chat Completions，要求模型按 JSON 结构返回段落 ID 与译文，不执行模型生成的 HTML。模型可配置；推荐采用官方当前支持的非思考模式。参见[接入说明](https://api-docs.deepseek.com/)和[定价](https://api-docs.deepseek.com/quick_start/pricing/)。

配置检查不会消耗翻译额度，它不能替代真实密钥、余额和模型权限验证。插件不会代替你购买额度或设置服务商账户的消费上限；请在服务商侧管理预算。

## OpenAI 兼容服务

这个选项为基础兼容适配器，服务需要支持 Chat Completions 请求与结构化 JSON 输出。接口行为、费用、模型和数据政策由你的服务商决定。

1. 选择兼容服务，填写可信服务的 **基础地址**与准确模型名并保存，远程地址必须为 HTTPS；本机回环地址允许 HTTP。
2. 在 Tampermonkey 菜单设置兼容服务 API Key。
3. 自定义主机未预先授权时，在 Tampermonkey 编辑器的脚本头添加对应主机，例如 `// @connect translate.example.org`。此处是虚构示例，请替换为实际主机。
4. 保存脚本，检查 Tampermonkey 的连接授权提示，再执行连接配置检查并用少量文本验证。

**填写 URL 不会自动授权任意域名。** 脚本默认不使用 `@connect *`。只有你主动添加并允许的主机才能用于跨域请求；若服务重定向到其他主机，需另外核对目标主机是否可信及是否授权。更新脚本后，重新核对手动添加的 `@connect`。

不要把密钥放在地址的用户名、密码、查询参数或片段中。不要把与该服务无关的密钥提供给自定义端点。兼容服务可以看到请求中的文本和密钥，请只配置可信服务。

## 通用注意事项

- 自动翻译只在你主动为网站开启后运行；大量段落会增加云调用量。
- 切换引擎或语言后重新翻译；不同配置不复用彼此的缓存结果。
- 当前页面缓存仅存于内存，刷新后清空。清除缓存后再次翻译可能产生新调用。
- 取消可停止后续工作和中断请求，但已经到达云服务的调用仍可能计费。
- 网络失败、限流或服务异常可能有限重试；认证、余额和配置错误需要用户处理。
