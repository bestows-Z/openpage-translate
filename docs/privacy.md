# 隐私、存储与权限

OpenPage Translate 不运营翻译服务器，不收集遥测，不设置项目账号，不向维护者提交页面内容或密钥。翻译数据的去向取决于你选择的引擎。

## 数据流

| 数据                           | 去向                                 | 保存方式                             |
| ------------------------------ | ------------------------------------ | ------------------------------------ |
| 浏览器本地翻译文本             | 浏览器内置翻译能力                   | 页面内处理；语言包由浏览器管理       |
| Ollama 翻译文本                | 配置的本机回环服务                   | 模型与服务日志由本地 Ollama 配置决定 |
| 有道 / DeepSeek / 兼容服务文本 | 所选服务的接口                       | 服务商的数据政策适用                 |
| API Key / 有道应用密钥         | 脚本存储、所选服务请求或有道本地签名 | Tampermonkey GM 存储                 |
| 引擎、语言、站点规则           | 脚本存储                             | Tampermonkey GM 存储                 |
| 译文缓存                       | 当前网页会话                         | 有界内存缓存，刷新后清空             |

项目不会把当前页面翻译缓存持久保存或上传。浏览器语言包下载、Tampermonkey 更新检查、用户手动下载 Ollama 模型会产生相应网络活动，它们不等于项目收集网页内容。

## 何时读取与发送文本

点击翻译、Alt + T、划词翻译，或为当前网站开启自动翻译规则后，脚本读取可翻译的页面文本。它会跳过代码、表单、编辑区、隐藏区域和标记为不翻译的内容，但不以这些规则判断文本是否敏感。

选择云引擎后，正文或选中文字会发送给该服务。该文本可能包含网页可见的个人信息，请依据页面内容选择本地引擎或禁用该网站。已发送的请求可能按服务商政策保留或计费；按停止不能撤回已经到达服务商的数据。

## 密钥保存

凭据通过 Tampermonkey 菜单设置，页面面板不显示已有密钥。不使用网站 `localStorage`、URL、公开 DOM、日志或仓库保存密钥。

GM 存储是脚本管理器的客户端存储，**不是硬件密钥库**。可信设备、浏览器及脚本管理器是这一边界的前提。管理器的数据导出、同步或备份行为可能影响凭据的保存范围，请自行核对其设置。

DeepSeek 和兼容接口的 Key 会发送至其对应接口；有道应用密钥用于本地生成签名，应用 ID 与签名发送至有道。不在普通网页与 GM 权限间桥接密钥。网页翻译结果始终按文本插入，不执行供应商或模型返回的 HTML。

## 用户脚本权限

| 权限 / 元数据                             | 用途                                                                |
| ----------------------------------------- | ------------------------------------------------------------------- |
| `@match http://*/*`、`@match https://*/*` | 在普通网页展示入口和处理文本；站点规则决定是否开始翻译              |
| `@noframes`                               | 不在 iframe 中重复运行                                              |
| `@sandbox DOM`                            | 请求脚本管理器以隔离的 DOM 上下文运行；不把 GM 能力或密钥桥接给网页 |
| `GM_getValue` / `GM_setValue`             | 保存设置、站点规则和凭据                                            |
| `GM_registerMenuCommand`                  | 通过油猴菜单设置凭据并提供入口                                      |
| `GM_setClipboard`                         | 用户点击划词结果复制按钮时，把译文写入剪贴板；不读取剪贴板          |
| `GM_xmlhttpRequest`                       | 跨域调用所选翻译服务及本机服务，支持取消                            |
| `@connect` 官方主机与回环地址             | 限定默认可连接目标，不默认授权任意域名                              |
| `@updateURL` / `@downloadURL`             | 由 Tampermonkey 检查与下载 GitHub Release 更新                      |

预设服务包括有道的 `openapi.youdao.com`、DeepSeek 的 `api.deepseek.com`、兼容服务预设 `api.openai.com`，以及本机 `localhost` / `127.0.0.1`。使用其他回环形式或自定义主机时需核对并添加授权。具体权限以安装文件的脚本头为准。

自定义主机需要用户在脚本头增加对应 `@connect` 并确认 Tampermonkey 授权。填写设置中的 URL 不能自动获得域名权限。重定向主机也应逐项核对；不要添加 `@connect *` 来跳过判断。更新后，手动添加的域名可能需要重新检查。

远程端点必须使用 HTTPS；本机回环服务可使用 HTTP。请求不携带网站 Cookie。项目不要求把本机服务对公网开放。

## 清理与撤销

- 清除页面缓存：删除当前会话中的译文缓存；不会撤销已发送请求。
- 还原页面：只移除脚本生成的译文和标记，保留网站之后产生的变化。
- 停止翻译：终止当前任务与后续排队工作，保留已显示的译文。
- 清除凭据：通过油猴菜单重新设置为空，或使用管理器的脚本数据管理功能。
- 删除脚本：按 Tampermonkey 的提示处理脚本存储，刷新已打开页面。
- 撤销服务访问：到服务商控制台撤销对应密钥；这比只删除本地值更彻底。

界面使用 closed Shadow DOM 隔离样式，不把它宣传为对任意恶意网页的完整安全防护。客户端脚本的运行边界仍取决于浏览器、管理器与所在页面环境。

请勿在 Issue、截图、补丁或聊天中公开真实密钥。安全问题见[安全政策](../SECURITY.md)。
