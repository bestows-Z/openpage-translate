## 自动化覆盖

单元测试验证文本分段、语言映射、源语言处理、缓存隔离、签名及响应校验等逻辑。页面集成测试验证双语插入、动态内容、原文变化、停止/还原后的迟到响应和译文作为纯文本插入等行为。已实现的具体用例以 `tests/` 和 CI 运行结果为准。

本次还验证了设置变更后的重新翻译、划词设置与复制、清除密钥后取消划词请求、有道应用 ID 留空后停止任务，以及在设置输入中按 Alt + T 不触发翻译。
