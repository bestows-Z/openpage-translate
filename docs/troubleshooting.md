# 问题排查

记录浏览器、Tampermonkey、脚本版本和所选引擎。先在可公开的普通文章页复现，避免提供敏感网页或密钥。

## 安装后没有入口

- 确认 Tampermonkey 和脚本均已启用，随后刷新页面。
- 按[官方说明](https://www.tampermonkey.net/faq.php?ext=mfdh&q=Q209)允许用户脚本运行；不同浏览器版本可能显示“允许用户脚本”或要求开发者模式。
- 如果入口存在而无法开始翻译，确认当前网站没有禁用规则。
- 浏览器内部页面、扩展商店、PDF 查看器及某些受保护页面不能按普通网页执行脚本。
- iframe 中不重复注入脚本；进入顶层页面后重试。

## 浏览器本地翻译不可用

浏览器内置网页翻译功能与可供脚本调用的 Translator API 不是同一入口。当前浏览器有翻译菜单，不代表油猴能访问本地 API。

检查普通 HTTPS 页面、所选语言对、浏览器更新、语言包下载和网站策略。如果自动判断源语言失败，手动选择。若依然不可用，选择本机 Ollama；脚本不会自动改用云服务。不要因实验功能不可用而向未知网站提供密钥。

## Ollama 连接失败或模型不存在

确认 Ollama 服务已启动，地址为本机回环地址，模型已完整下载且名称一致。连接检查需要访问本机服务的模型列表。脚本拒绝非回环 Ollama 地址及被识别为云模型的配置。

查看 Tampermonkey 是否允许 `localhost` 或 `127.0.0.1`。本机访问与云网页的浏览器网络策略可能不同；请先检查本机服务和管理器提示，不要将服务暴露公网或盲目允许全部来源。

若模型无法输出要求的 JSON，可更换支持结构化输出的本地模型，或缩小文本规模。低性能设备可能需要更长时间处理。

## 有道认证、余额或服务错误

- 应用 ID 是 `appKey`，应用密钥是对应应用的密钥；不要填写有道账户密码。
- 确认该应用已绑定自然语言翻译服务，控制台配额和余额可用。
- 50 元体验资金是试用额度，耗尽后不是继续免费调用。
- 核对计算机时间；签名请求包含时间，明显偏差可能导致失败。
- 配置检查只验证本地值，不代表实际账户可用。请根据翻译时返回的业务错误处理；不要反复提交无效密钥。

错误码说明见[有道接口文档](https://ai.youdao.com/DOCSIRMA/html/trans/api/wbfy/index.html)。

## 云服务返回错误

| 现象                           | 处理                                      |
| ------------------------------ | ----------------------------------------- |
| HTTP 401 / 403                 | 检查密钥、服务账户与模型权限              |
| HTTP 402 / 余额不足            | 在服务商控制台核对余额，不继续重复调用    |
| HTTP 429                       | 停止当前任务，稍后重试并检查账户配额      |
| HTTP 5xx / 超时                | 确认服务状态和网络，稍后重试              |
| 返回无效 JSON 或段落 ID 不匹配 | 核对模型和结构化输出支持，切换兼容模型    |
| 请求未获授权 / 连接失败        | 核对油猴 `@connect`、服务地址及重定向主机 |

停止请求不保证云服务免收已经收到的调用费用。不要在错误报告中粘贴完整请求头或密钥。

## 自定义兼容服务无法连接

设置中应填写基础地址，远程使用 HTTPS，不含用户名、密码、查询参数或片段。自定义域名需要在用户脚本头增加具体主机的 `@connect`；填写 URL 不会自动授权。若更新覆盖了手动编辑的脚本头，请重新核对。

同时确认服务支持 Chat Completions 与 JSON 输出，以及模型名正确。服务声称兼容不代表它支持适配器使用的所有参数。

## 部分段落没有翻译

同目标语言的内容、代码、输入区、编辑区、隐藏区域和 `translate="no"` 区域会跳过。图片内文字、Canvas、跨域 iframe 和封闭 Shadow DOM 当前不处理。

新内容会动态扫描；特殊网站的虚拟列表或频繁改写 DOM 可能不稳定。若原文在请求期间变化，旧译文会被丢弃以避免插入错误结果。可以停止并还原后，重新开始。

## 快捷键或划词入口没有反应

Alt + T 在输入和编辑场景中可能不会触发，网站或浏览器也可能占用快捷键。使用页面按钮或 Tampermonkey 菜单入口。划词翻译需要先在普通网页文字中建立非空选区，再点击浮动按钮。
